# HR Analytics Dashboard | Tableau

## Project Overview
An interactive HR Analytics Dashboard developed using Tableau to analyze employee data and understand workforce trends.

## Objectives
- Analyze employee attrition.
- Understand employee demographics.
- Identify department-wise employee distribution.
- Analyze job satisfaction.
- Explore salary and overtime trends.

## Tools & Technologies
- Tableau
- Microsoft Excel
- Data Visualization
- Data Analytics

## Key Features
- Interactive filters
- Employee demographics analysis
- Attrition analysis
- Department-wise insights
- Job satisfaction analysis

## Project Files
- HR-DASHBOARD.twbx – Tableau workbook
- dataset.csv – Dataset
- Assets – Dashboard images and icons
